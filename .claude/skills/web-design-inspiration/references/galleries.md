# Where to find fresh inspiration

Use these to refresh references, find industry-specific examples, or show the user where to browse. When you can search the web, search *within* these (e.g. `site:awwwards.com restaurant`) rather than relying on listicles, which recycle years-old examples.

## Award and curated galleries

| Gallery | Best for | Tip |
| --- | --- | --- |
| **awwwards.com** | Cutting-edge, jury-judged sites. Site of the Day, of the Month, of the Year | Filter by category (e.g. `/websites/architecture/`), technology or colour. "Sites of the Day" shows what's current |
| **thefwa.com** | Experimental, interactive, since 2000 | Heavy on WebGL and campaigns |
| **godly.website** | Motion and interaction-heavy sites, with video previews | Good for "how should this move?" |
| **siteinspire.com** | Clean, minimal, typographic sites | Filter by style, type and subject |
| **land-book.com** | Landing pages, by category | Good for SaaS and product pages |
| **lapa.ninja** | Landing pages with full-page screenshots | Large archive by category |
| **onepagelove.com** | One-page sites and templates | Portfolios, events, launches |
| **saaslandingpage.com / saasframe.io** | SaaS pages broken down by section | Find "pricing pages" or "heroes" specifically |
| **mobbin.com** | Real app and web UI flows (onboarding, checkout) | Best for product UI, not marketing |
| **cssdesignawards.com** | Awards similar to Awwwards | Second opinion on what's current |
| **httpster.net, minimal.gallery, hoverstat.es** | Small curated feeds | Fresher, less mainstream picks |
| **bestwebsite.gallery** | Long-running archive, searchable by colour | Colour inspiration |
| **typewolf.com** | Font use in the wild, site of the day | "What font is this site using?" |
| **brutalistwebsites.com** | Brutalist archive | Raw and anti-grid references |
| **darkmodedesign.com** | Dark UI sites | Dark dev-tool references |

## Component and template sources

- **Framer templates / Webflow showcase**: whole sites in current styles, good for seeing a style applied end to end.
- **ui.shadcn.com, magicui.design, aceternity.com/ui**: modern React components (bento, glow cards, marquees, animated beams) in the current SaaS look.
- **neobrutalism.dev**: neo-brutal components.
- **spline.design community**: 3D scenes you can embed.

## Quick research recipe

1. Search `<industry> website design site:awwwards.com` and `best <industry> websites <current year>`.
2. Search the chosen style name plus "website examples" for that style.
3. Prefer recent Sites of the Day and gallery entries over listicles, and say when you couldn't verify that a site is still live in that style.
4. Note the specific element worth studying on each site (hero, nav, type, motion), not just its name.
